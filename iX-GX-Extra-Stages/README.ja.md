# iX/GX エクストラステージ

[English](README.md)

Steam版「Azure Striker Gunvolt Trilogy Enhanced」に収録されているGX用の小さなWindowsツールです。
プレイ中のモードのミッション選択にステージを追加します。

- **GX（ストーリーモード）：** ガンヴォルト３のステージ「双極の紫背者」（紫電戦）と「新世界の王」（アシモフ戦）を
  ミッション選択に追加します。
- **CONNECT X：** GXの全ミッションと、ガンヴォルト３の双極の紫背者・新世界の王を、イクス版のコピンで遊べます。
  出撃ごとにGXの難易度も選べます。

また、新世界の王（アシモフ戦）の途中でゲームが落ちる不具合も修正します。

ディスク上のファイルは一切変更しません。変更は起動中のゲームのメモリ上だけで、ツールを閉じるとゲームは元に戻ります。
最初に何かを変更する前に、セーブフォルダを自動でバックアップします。

## ダウンロードと使い方

[Releases](../../releases) ページから最新のzip（日本語版または英語版）をダウンロードし、好きな場所に展開して .exe を
実行してください。詳しい使い方：[使い方 (iX-GX エクストラステージ).txt](docs/使い方%20(iX-GX%20エクストラステージ).txt)

動作環境：Windows 10 / 11（64ビット）、Steam版「Azure Striker Gunvolt Trilogy Enhanced」。

## ビルド

ツールは C# のファイル１つで、Windows に付属している C# コンパイラ（.NET Framework 4）でビルドできます。
`build.cmd` を実行すると、英語版と日本語版の両方の exe ができます。

```bat
build.cmd
```

[改造メモ (iX-GX エクストラステージ).txt](docs/改造メモ%20(iX-GX%20エクストラステージ).txt) に、このツールを作る過程で
分かったことをすべてまとめています：ゲームのファイルとデータ形式、ステージ番号、ミッション一覧、メニューの解放条件、
